# 🌸 Iris Dataset Classification with Logistic Regression

This project demonstrates a simple classification model using the famous **Iris flower dataset** and **Logistic Regression** in Python. It includes data visualization, model training, and evaluation.

---

## 📊 Dataset

The Iris dataset is a classic dataset in machine learning, containing 150 samples of iris flowers with 4 features:

- Sepal length
- Sepal width
- Petal length
- Petal width

Each sample is classified into one of the 3 species:
- Iris Setosa
- Iris Versicolour
- Iris Virginica

---

## 🧪 What’s Inside

- 📊 **Data Visualization** using seaborn’s `pairplot`
- 🔢 **Model**: Logistic Regression (multi-class)
- 📈 **Evaluation**: Accuracy Score, Confusion Matrix, and Classification Report

---
